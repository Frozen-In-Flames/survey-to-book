survey-to-book: the proof-of-works library

Each book in this library was generated locally and offline by survey-to-book from one fictional respondent's answers to a genre survey: proof of works for the genre pack named on the book. From the second book onward the respondent is the series' demonstration user, the fictional persona Frozen In Flames, drawn from one canonical character record, so the same character headlines every book. The first book's respondent is the fictional persona June Calloway.
